# ⚽ Sports Prediction Engine (베트맨 프로토 AI 분석 도구)

> 베트맨 프로토 승부식의 경기·배당·결과를 **매일 자동으로 수집**합니다. 베트맨 과거 2.3만 경기로 학습한 AI가 **베트맨 배당의 버릇을 보정한 확률**을 계산하고, 조합 시뮬레이션과 과거 백테스트, **정직한 성적표**를 대시보드로 보여 줍니다.
> 100% 무료 서버리스: GitHub Actions(수집·학습·채점) + JSON 파일 저장소 + Streamlit 대시보드.

> ⚠️ **투자 조언이 아닙니다.** 베트맨 환급률은 약 85%라 장기 수익은 구조적으로 매우 어렵습니다. 이 도구의 AI는 "시장보다 조금 더 정확"하다는 근거는 있지만, **"돈을 번다"는 근거는 아직 없습니다** (아래 [현재 상태](#-현재-상태-2026-10) 참고).

```
베트맨 수집(현재 회차 경기·배당 + 지난 회차 결과)
  → 해외 배당 비교(The Odds API, 회차당 하루 1회)
  → AI 확률 계산(베트맨 학습 보정 모델) → 경기 시작 전 예측 고정 저장
  → 전략별 가상 베팅 생성 → 결과 나온 경기 채점 → 공식 성적표·가상 베팅 리그 갱신
매주 수요일 아침: 유럽 데이터 + 베트맨 과거 결과 추가 수집 → AI 재학습 (검증 통과 시에만 실전 반영)
```

## 🧠 AI는 무엇을 하나
- **출발점은 시장(베트맨 배당) 확률입니다.** AI는 처음부터 확률을 만들지 않고 **"베트맨이 어디서 틀리는지"만 학습**합니다 (`models/betman_corrector.py`).
- 학습 데이터는 베트맨 2023~2026년 **23,325경기**입니다. 유럽 리그뿐 아니라 K리그·J리그·MLS·국가대표전도 들어 있습니다 (`collector/betman_archive.py`).
- **찾아낸 베트맨의 버릇:**
  - 강팀 승리 확률을 낮게 잡습니다.
  - 무승부 확률을 조금 낮게 잡습니다.
  - 리그마다 홈/원정 편향이 다릅니다.
- **효과가 없어서 넣지 않은 정보:** 팀 실력(Elo), 언더/오버로 본 예상 득점, 휴식일, 배당 구조. 모두 베트맨 배당에 이미 반영되어 있었습니다 (실험: `models/betman_experiments.py`, TODO 5.7).
- **안전장치:** 학습 기간에 쓰지 않은 데이터로 시험해서 시장보다 나을 때만 실전에 씁니다. 그렇지 않으면 자동으로 배당 확률로 돌아갑니다.

## 🖥️ 대시보드 사용법 (`streamlit run dashboard/app.py`)

### ① 맞춤조건구매 (시뮬레이터)
- **🧩 조합 찾기:** 데이터로 확인한 원칙으로 이번 회차 2~3폴더 후보를 만듭니다. 원칙은 저배당 강팀 축, AI ▲, 💎 우선, 전배 없음입니다. 각 후보에는 **과거 반복 결과**가 함께 나옵니다.
- **STEP 01, 경기 카드:** 배당 버튼을 눌러 선택합니다. 회차·날짜·리그·유형 필터와 **전체 회차 보기**를 지원합니다.

  | 표시 | 뜻 |
  |---|---|
  | ⭐ | AI 확률 1순위 (AI가 없으면 배당 1순위) |
  | 💎 | AI 기준 기대가치 플러스 (**검증 중**) |
  | ▲ / ▼ | AI가 배당보다 높게 / 낮게 본 정도 (%p) |
  | ⚠️ 다름 | AI 1순위가 배당 1순위와 다름 |
  | ✅ / ❌ | 끝난 경기의 배당 예상·AI 예상 적중 여부 (AI는 경기 전 기록으로만 채점) |

- **STEP 02, 조합 결과:** 표에서 조합 선택과 금액을 직접 수정합니다. 총 투표금액, 적중 시 환급, 하나라도 맞을 확률, **기대 손익**이 표시됩니다.
  - **🔁 이 방식을 과거에 반복했다면?** 지금 고른 조합 방식을 과거 500여 회차에 적용해 **실제 결과**로 계산합니다.
  - 베팅 슬립 복사와 켈리 계산기(고급)도 있습니다.

### ② AI 경기 분석
- 현재 AI의 검증 성적, 경기별 배당 확률 vs AI 확률, 기대가치, 최근 폼을 봅니다.

### ③ 성과 검증
- **🏅 공식 AI 성적표:** 경기 전에 고정 저장한 예측만 실제 결과로 채점합니다 (Log loss AI vs 시장, 신뢰구간, 날짜별 추이). **AI 실력의 공식 지표**입니다.
- **🧪 가상 베팅 리그:** 전략 5개(💎 단일 / 강팀 2폴더 / 조합 찾기 1순위 / 축+전배 / **배당 1순위 기준선**)의 가상 수익을 자동으로 누적합니다. 실제 구매는 하지 않습니다.

## 📊 현재 상태 (2026-10)
| 항목 | 상태 |
|---|---|
| AI가 베트맨 배당보다 정확한가 (과거 시험) | ✅ 2025년 4개 분기 모두 우세. 2026년 4,306경기 LL −0.0021 [−0.0044, +0.0001] |
| AI가 실전에서도 정확한가 (공식 성적표) | ⏳ 2026-10-25부터 기록 시작, 300경기(약 2~3주) 후 1차 판단 |
| AI를 따라 걸면 돈이 남는가 | ❌ 근거 없음. 보정 폭(경기당 1~3%p)이 마진(약 15%)보다 작음 |
| 조합 데이터 분석 | 1.0~1.3배 강팀 2폴더가 가장 덜 잃음(−7.3%). 축+전배는 축만 걸 때보다 손실이 큼(−24.7% vs −11.5%) |
| AI 조합·금액 추천 | 🔒 가상 베팅 리그에서 수익이 입증된 전략이 생길 때만 켜짐 (TODO 5.10) |

## ⚙️ 로컬 실행
```bash
pip install -r requirements.txt
git pull                                  # 봇이 하루 2번 data/를 커밋하므로 먼저 최신화
streamlit run dashboard/app.py            # 대시보드 (localhost:8501)

# 직접 돌려 보기 (data/ 파일이 바뀌므로 커밋하지 말 것 — GEMINI.md 참고)
python run_pipeline.py                    # 수집 → 예측 → 채점 1회
python -m models.betman_corrector         # 베트맨 학습 AI 재학습·검증
python -m models.betman_experiments elo   # 피처 실험 (walk-forward)
python -m pytest -q                       # 테스트
```

   - **Branch:** `master`
   - **Main file path:** `dashboard/app.py`

4. Actions가 `data/`를 커밋하면 클라우드 대시보드에 자동으로 반영됩니다. `git pull`이 필요 없습니다.
