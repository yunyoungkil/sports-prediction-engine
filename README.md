# ⚽ Sports Prediction Engine (베트맨 프로토 AI 분석 도구)

> 베트맨 프로토 승부식의 경기·배당·결과를 **매일 자동으로 수집**합니다. 베트맨 과거 2.3만 경기로 학습한 AI가 **베트맨 배당의 버릇을 보정한 확률**을 계산하고, 조합 시뮬레이션과 과거 백테스트, **정직한 성적표**를 대시보드로 보여 줍니다.
> 100% 무료 서버리스: GitHub Actions(수집·학습·채점) + JSON 파일 저장소 + Streamlit 대시보드.

> ⚠️ **투자 조언이 아닙니다.** 베트맨 환급률은 약 85%라 장기 수익은 구조적으로 매우 어렵습니다. 이 도구의 AI는 "시장보다 조금 더 정확"하다는 근거는 있지만, **"돈을 번다"는 근거는 아직 없습니다** (아래 [현재 상태](#-현재-상태-2026-10) 참고).

```

  → AI 확률 계산(축구 승무패 + 유형별 보정 모델) → 경기 시작 전 예측 고정 저장
```

## 🧠 AI는 무엇을 하나
- **출발점은 시장(베트맨 배당) 확률입니다.** AI는 처음부터 확률을 만들지 않고 **"베트맨이 어디서 틀리는지"만 학습**합니다 (`models/betman_corrector.py`).
- 학습 데이터는 베트맨 2023~2026년 **23,325경기**입니다. 유럽 리그뿐 아니라 K리그·J리그·MLS·국가대표전도 들어 있습니다 (`collector/betman_archive.py`).
- **찾아낸 베트맨의 버릇:**
  - 강팀 승리 확률을 낮게 잡습니다.
  - 무승부 확률을 조금 낮게 잡습니다.
  - 리그마다 홈/원정 편향이 다릅니다.
- **축구 승무패 외 유형:** 2023~2026년 **19만 행**(전 종목·전 유형)으로 유형마다 같은 방식의 보정을 학습합니다 (`models/betman_markets.py`). 시험을 통과한 **축구 핸디캡**(강팀 저평가가 승무패와 같음)과 농구 승패에만 적용하고, 나머지(언더오버, 홀짝, 야구, 배구 등)는 베트맨 배당이 이미 정확해서 배당 기준을 유지합니다.
- **효과가 없어서 넣지 않은 정보:** 팀 실력(Elo), 언더/오버로 본 예상 득점, 휴식일, 배당 구조. 모두 베트맨 배당에 이미 반영되어 있었습니다 (실험: `models/betman_experiments.py`, TODO 5.7).
- **안전장치:** 학습 기간에 쓰지 않은 데이터로 시험해서 시장보다 나을 때만 실전에 씁니다. 그렇지 않으면 자동으로 배당 확률로 돌아갑니다.

## 🖥️ 대시보드 사용법 (`streamlit run dashboard/app.py`)

### ① 맞춤조건구매 (시뮬레이터)
- **🧩 조합 찾기:** 데이터로 확인한 원칙으로 이번 회차 2~3폴더 후보를 만듭니다. 원칙은 저배당 강팀 축, AI ▲, 💎 우선, 전배 없음입니다. 각 후보에는 **과거 반복 결과**가 함께 나옵니다.
- **STEP 01, 경기 카드:** 배당 버튼을 눌러 선택합니다. 회차·날짜·리그·유형 필터와 **전체 회차 보기**를 지원합니다.

  | 표시 | 뜻 |
  |---|---|
  | ⭐ | AI 확률 1순위 (AI가 없으면 배당 1순위) |
  | 💎 | AI 기준 기대가치 플러스 (**검증 중**) |
  | ▲ / ▼ | AI가 배당보다 높게 / 낮게 본 정도 (%p) |
  | ⚠️ 다름 | AI 1순위가 배당 1순위와 다름 |
  | ✅ / ❌ | 끝난 경기의 배당 예상·AI 예상 적중 여부 (AI는 경기 전 기록으로만 채점) |

- **STEP 02, 조합 결과:** 표에서 조합 선택과 금액을 직접 수정합니다. 총 투표금액, 적중 시 환급, 하나라도 맞을 확률, **기대 손익**이 표시됩니다.
  - **🔁 이 방식을 과거에 반복했다면?** 지금 고른 조합 방식을 과거 500여 회차에 적용해 **실제 결과**로 계산합니다.
  - 베팅 슬립 복사와 켈리 계산기(고급)도 있습니다.

### ② AI 경기 분석
- 현재 AI의 검증 성적, 경기별 배당 확률 vs AI 확률, 기대가치, 최근 폼을 봅니다. 목록에는 **회차·상태(발매 중/마감/경기 중/종료)·마감 시각·점수·결과·AI 적중**이 나오고 상태·회차로 거를 수 있습니다.

### ③ 성과 검증
- **🏅 공식 AI 성적표:** 경기 전에 고정 저장한 예측만 실제 결과로 채점합니다 (Log loss AI vs 시장, 신뢰구간, 날짜별 추이). **AI 실력의 공식 지표**입니다. **정확도(LL)와 함께 보정 지표(Brier·ECE)**, 서로 다른 대진 수, 유형별 성적을 병기합니다.
- **📈 마감 배당 비교 (CLV):** AI가 높게 본 쪽으로 마감 때 배당이 내려갔는지 봅니다. 운이 덜 섞여 성적표보다 빨리 방향을 알 수 있습니다.
- **🧪 가상 베팅 리그:** 전략 7개(💎 단일 / 강팀 2폴더 / 조합 찾기 1순위 / 축+전배 / **배당 1순위 기준선** / F: AI 조합 묶음+켈리 금액 / **G: 자율 AI 베터**)와 비교용 **G-본능**의 가상 수익을 자동으로 누적합니다. 실제 구매는 하지 않습니다. **G**는 월 10만 원 지갑(번 돈은 내 돈, 바닥나면 다음 달 1일까지 쉼)으로 매 회차 안정 조합 1장 + 소액 복권 1장을 사람처럼 사고, 금액은 AI가 정하되 밑천은 월 용돈 기준으로 매월 1일에 한 번 정해 고정합니다(용돈이 쌓여도 판돈은 안 커지고 번 만큼만 커짐). 카드에 지갑·순손익·슬립별 성적·"판돈 조절 효과"(같은 베팅을 1,000원 고정으로 걸었을 때와 비교)가 나옵니다. **G-본능**은 G와 같은 경기를 사되 사람의 본능대로(이기면 다음 회차 판돈 ×1.4, 지면 복권을 15~50배로, 수익 보호 없음) 거는 비교판으로, 과거 28개월 재현에서는 G −62만 원 vs G-본능 −136만 원이었습니다.


### ④ 내 베팅 기록
- 사이드바 "저장하기"로 남긴 선택(실제 구매 / 가상 구매)의 경기별 결과·조합별 환급·손익을 자동 채점합니다. **내 수익률 vs 기준선**(그냥 배당 1순위를 샀다면)과 "무엇을 보고 골랐을 때 잘 맞았나"도 봅니다.
- `user_data/`에만 저장되고 GitHub에는 올라가지 않습니다 (PC 간 공유는 GEMINI.md 6번).
