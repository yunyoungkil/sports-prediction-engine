# ⚽ Sports Prediction Engine (스포츠 승부 예측 & 가치 픽 시스템)

> **베트맨(Betman) 프로토 승부식 데이터를 자동으로 수집하고, 오픈소스 스포츠 퀀트 모델(`penaltyblog`)을 활용해 승부 예측 및 기대가치(EV, Expected Value) 분석을 수행하는 100% 무료 서버리스 시스템입니다.**

---

## 🎯 프로젝트 목적
* **정보의 객관화:** 감정이나 팬심, 네티즌 댓글의 노이즈에 휘둘리지 않고 순수 통계 데이터(홈/원정 폼, 휴식일수, 포아송 기대득점)로 승률 계산.
* **가치 픽(Value Bet) 탐색:** 단순히 승패만 찍는 것이 아니라, 베트맨 오즈메이커가 제시한 배당 대비 AI 예측 승률이 더 높아 장기적으로 수학적 기대가치($EV > 0$)가 있는 경기를 자동 탐색.
* **100% 무인 자동화:** 사람이 매일 켤 필요 없이, GitHub Actions가 정해진 요일에 자동으로 데이터를 긁어와 예측을 돌리고 Streamlit 웹 대시보드로 실시간 동기화.

## 🚀 고도화 계획 (v2)

> **원칙:** 기능을 더 붙이기 전에, **모델이 시장(배당)보다 나은지부터 측정할 수 있게 만든다.**
> 측정이 안 되면 어떤 개선이 효과가 있었는지 알 수 없다.

### 현재 상태 진단 (2026-10 기준)
* 실전 채점 결과: 1,127건 베팅, 적중률 50.6%, **ROI −4.08%** (S등급은 적중률 53.7%인데 ROI −6.1%)
* 백테스트 ROI(+21.59%)와 실전 ROI의 차이가 커서 상수 과최적화가 의심됨
* 학습 데이터가 2024/25 시즌까지라 오래됐고, 시간 가중치가 없음
* 비축구 종목과 매핑 실패 팀은 "모델 확률"이 사실상 배당 역수 + 폼 보정임
* 자동화 결함: 회차 번호 `260126` 고정, 실전 결과 파일 미갱신, Actions에 텔레그램 Secret 미연결

### 단계 요약

| 단계 | 이름 | 목표 | 예상 기간 |
|---|---|---|---|
| **Step 0** | 무인 자동화 복구 | 회차 자동 탐지, 결과 누적 수집, 알림 연결로 진짜 무인 운영 | 1~2시간 |
| **Phase 1** | 측정 기반 | 시장 기준선 대비 Log loss·Brier·CLV로 모델을 객관적으로 평가 | 1~2주 |
| **Phase 2** | 모델 기본기 보강 | 데이터 최신화, 시간 가중치, 리그별 모델, 팀명 매핑 정리, xG 피처 | 2~4주 |
| **Phase 3** | 시장과 결합 | 샤프 배당(Pinnacle) 대비 베트맨 오가격 탐지, 모델과 시장 확률 블렌딩 | 3~6주 |
| **Phase 4** | 자금 관리와 제품 | 분수 켈리, 조합 재검토, 대시보드 정직화, 테스트와 CI | 2~3주 |

### 의사결정 체크포인트
| 시점 | 조건 | 다음 행동 |
|---|---|---|
| Phase 1 완료 | 모델 Log loss가 시장 기준선보다 나쁨 | Phase 2에 집중하고, 추천 기능은 잠시 중단 |
| Phase 3 완료 | 블렌딩 계수 b ≈ 0 (모델이 시장에 더하는 정보 없음) | 자체 모델 대신 샤프 시장 대비 오가격 탐지로 방향 전환 |
| 실전 300건 이상 | CLV가 양수이고 ROI 95% 신뢰구간이 0을 넘음 | 그때 베팅 금액 확대를 검토 |

> ⚠️ 베트맨 환급률은 약 85% 안팎이라 장기 수익은 구조적으로 매우 어렵다. 이 프로젝트의 수치는 투자 조언이 아니다.

## ⚙️ 빠른 시작 (로컬 테스트)

```bash
# 1. 의존성 패키지 설치
pip install -r requirements.txt

# 2. 파이프라인 1회 수동 실행 (데이터 수집 -> AI 예측 -> JSON 저장)
python run_pipeline.py

# 3. Streamlit 대시보드 실행
streamlit run dashboard/app.py
```
